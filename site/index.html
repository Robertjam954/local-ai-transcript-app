Turn speech into clean text - privately, on your own device.

Record in the browser, drop in an audio file, or paste a messy transcript. On-device Whisper turns it into text and a provider-agnostic LLM cleans it up - removing filler, fixing errors, and keeping the facts. No audio ever leaves your machine.

The live demo runs the real React UI with simulated transcription, cleanup, and transcript search; the Whisper demo runs actual on-device speech-to-text in your browser. The full app runs Whisper and an LLM locally on your machine.

What it does

Private transcription, cleaned up

Everything runs locally - a real, working app, not a hosted mockup that ships your audio to the cloud.

🎙️

Browser recording

Capture speech straight from the mic, with a hold-V shortcut to record hands-free.

📁

Audio upload

Drag and drop or pick a file - mp3, wav, webm, ogg, and m4a all work out of the box.

📝

Paste-text cleanup

Already have a messy transcript? Paste it in, skip transcription, and go straight to cleanup.

🔒

Local Whisper STT

English speech-to-text with faster-whisper that auto-selects GPU (Metal/CUDA) or CPU. Audio stays on-device.

✨

LLM transcript cleanup

An editable system prompt strips filler, fixes grammar and STT errors, and preserves names, numbers, and action items.

🔌

Provider-agnostic

Works with any OpenAI-format API - local Ollama, LM Studio, the OpenAI API, or others - via simple .env config.

Under the hood

Architecture

A React + Vite frontend talking to a FastAPI backend that runs Whisper locally and delegates cleanup to any OpenAI-compatible model.

Browser (React 19 + Vite + TypeScript)
  │ HTTP · relative /api/*
FastAPI backend · Python 3.12 · uvicorn (local-first, no cloud required)
  ├─ faster-whisper — on-device speech-to-text (Metal / CUDA / CPU)
  └─ OpenAI-compatible LLM — transcript cleanup (Ollama · LM Studio · OpenAI)
FastAPI · Python 3.12 React 19 · Vite · TypeScript faster-whisper STT Ollama · LM Studio OpenAI-compatible API Devcontainer ready

Run it yourself in minutes

Clone the repo and start the stack - the devcontainer bundles the app and a local Ollama model, so it runs with zero cloud dependency.

# clone and open in the devcontainer, then:
$ git clone https://github.com/Robertjam954/local-ai-transcript-app
$ cd backend && uvicorn app:app --port 8000
$ cd frontend && npm install && npm run dev

English-only out of the box; runs a small local LLM on CPU by default - free and private, and easy to upgrade to a stronger or hosted model.
